# dsl_library_tool_v1

Ứng dụng GUI quản lý thư viện DSL (Domain Specific Language cho cắt laser).

## Các file

- **main.py** — Entry point của tool.
- **dsl_parser.py** — Parse các lệnh DSL (R, RC, P, M, C, A, ADD, END…).
- **dsl_canvas.py** — Canvas preview hình.
- **dsl_library.py** — Quản lý danh sách file trong thư viện.
- **dsl_library/** — Thư mục chứa các file `.txt` mẫu DSL (Car Frame, hw095, lm2596…).

Chạy: `python main.py`
