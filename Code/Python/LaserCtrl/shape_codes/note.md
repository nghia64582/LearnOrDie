# shape_codes

Thư viện các mẫu hình dạng chi tiết dùng cho cắt laser (định dạng DSL text).

## Các file

- **box_1.txt**, **box_2.txt** — Hộp.
- **battery_holder.txt** — Giá đỡ pin.
- **hinge_1.txt** — Bản lề.
- **gusset_1.txt** — Gusset / tấm gia cường.
- **edge_bar.txt**, **el_shape_bar.txt** — Thanh cạnh / thanh chữ L.
- **i_shape_bar_head_and_foot.txt**, **i_shape_bar_middle.txt** — Phần đầu/đuôi và giữa của thanh I.
- **triangle_footer.txt** — Chân tam giác.
- **draft.txt**, **draft_2.txt** — Bản nháp.

Dùng làm nguồn tham chiếu hoặc import vào các tool khác.
